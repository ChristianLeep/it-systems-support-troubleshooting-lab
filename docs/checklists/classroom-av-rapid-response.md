# Classroom AV Rapid Response Guide
### Quick Fix Checklist for Display & Microphone Issues

Use this guide before contacting the Help Desk.  
Most classroom display and audio issues can be resolved in under **2 minutes**.

---

# DISPLAY ISSUE: Screen Shows “No Signal”

If the projector or classroom display says **“No Signal”**, follow these steps:

---

## Check Physical Connections
- Ensure the HDMI cable is firmly plugged into:
  - Your laptop  
  - The classroom wall plate or projector  
- If using a USB-C/HDMI adapter:
  - Reseat the adapter securely  
  - Try unplugging and reconnecting

---

## Verify Correct Input Source
- Use the classroom control panel or projector remote.
- Confirm the selected input matches your cable:
  - HDMI 1  
  - HDMI 2  

---

## Enable External Display (Windows Shortcut)

Press: Windows + P


Choose:
- **Duplicate** (mirror screen)  
or  
- **Extend**

If the display appears — issue resolved ✅

---

## Check Display Settings (If Needed)

1. Right-click desktop  
2. Select **Display Settings**  
3. Click **Detect**  
4. Select **Extend these displays**  
5. Click **Apply**

---

### Still Not Working?
Contact Help Desk and provide:
- Room number  
- Laptop type (Dell / HP / Mac)  
- Cable type being used

# AUDIO ISSUE: Teams or Zoom Microphone Not Working

If participants cannot hear you during a meeting:

---

## Check If You Are Muted
- Ensure the microphone icon in Teams/Zoom is not muted.
- Speak and confirm audio activity bars move.

---

## Select Correct Microphone in Teams

In Microsoft Teams:

1. Click **Settings (⚙️)**  
2. Go to **Devices**  
3. Under **Microphone**, select:
   - USB Headset (if connected)  
   - Built-in Microphone (if not using headset)  

Speak and verify the test bar moves.

---

## Check Windows Microphone Settings

1. Right-click the speaker icon in taskbar  
2. Click **Sound Settings**  
3. Under **Input**, confirm the correct device is selected  
4. Speak and verify the input level bar responds  

---

## Reconnect USB Devices

If using a USB headset:

- Unplug the headset  
- Wait 5 seconds  
- Plug it back in  
- Recheck microphone selection in Teams  

---

### Still Not Working?
Contact Help Desk and provide:
- Room number  
- Device type (USB headset / built-in mic / podium mic)  
- Meeting platform (Teams / Zoom)

---

# Pro Tips for Instructors

- Test display and microphone **5 minutes before class**
- Use `Windows + P` for quick display switching
- Verify mic levels before starting live session
- Avoid connecting USB devices after joining the meeting
