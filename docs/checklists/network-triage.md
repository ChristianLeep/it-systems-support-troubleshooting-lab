# Network Quick Self-Check Guide
### Before Contacting the Help Desk

If you are connected to Wi-Fi or Ethernet but cannot access the internet, try these quick checks first.  
This guide is meant to rule out simple issues.

Most checks take under **2 minutes**.

---

# 1️⃣ Check Your Connection

### If Using Wi-Fi:
- Make sure you are connected to the correct network.
- Confirm the Wi-Fi icon shows signal bars (not disconnected).
- If possible, move closer to the access point.

### If Using Ethernet:
- Ensure the cable is firmly plugged in.
- Check that it is connected to the wall port.
- If the cable feels loose, unplug and reconnect.

---

# 2️⃣ Try Another Website

If one website will not load:

- Try a different website (example: google.com).
- If other sites work, the original site may be temporarily down.

---

# 3️⃣ Turn Wi-Fi Off and Back On

1. Click the network icon in the bottom-right corner.
2. Turn Wi-Fi off.
3. Wait 5 seconds.
4. Turn Wi-Fi back on.
5. Reconnect to your network.

---

# 4️⃣ Disconnect and Reconnect (Wired)

If using Ethernet:
- Unplug the cable.
- Wait 5 seconds.
- Plug it back in.
- Wait for connection to reestablish.

---

# 5️⃣ Restart Your Computer

Many temporary network issues resolve after a full restart.

- Save your work.
- Restart your device.
- Test internet access again.

---

# 6️⃣ Check If Others Have the Same Issue

Ask someone nearby:
- Are they able to access the internet?
- Is the issue only happening on your device?

This helps determine whether the issue is device-related or location-related.

---

# Contact Help Desk If:

- You cannot connect to Wi-Fi at all.
- Multiple websites will not load.
- You see “No Internet” or “Connected, No Internet.”
- The issue continues after restarting.

When contacting IT, please provide:
- Building / Room #
- Wired or Wi-Fi?
- Screenshot of any error message

---

# Why This Guide Exists

This checklist helps identify:
- Loose cables
- Wrong Wi-Fi network
- Temporary connection drops
- Browser or website issues
- Issues resolved by restart
